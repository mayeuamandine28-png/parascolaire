# 🧑‍🍳 Parascolaire — App Interactive de Cuisine

Application interactive pour les cours de cuisine parascolaires à l'**École Marie de France**, Montréal.

## 📋 Programme

- **CE2** — "Petits Chefs du Monde" (4 recettes: houmous, lassi, gaspacho, baghrir)
- **CM1-CM2** — "Apprentis Cuistots" (4 recettes: gaspacho, grilled cheese, croustade, brochettes)

## ✨ Fonctionnalités

- Recettes détaillées avec étapes numérotées
- Chronomètres pour cuisson/réfrigération
- Images des plats
- Thèmes couleur adaptés par niveau
- Interface mobile-friendly

## 🚀 Utilisation

Ouvrez `index.html` dans le navigateur.
